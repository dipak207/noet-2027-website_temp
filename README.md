# NOET 2027 Website

NOET 2027 conference website with a React/Vite frontend and Django REST backend.

## Production architecture

- React + Vite -> Vercel
- Django + DRF -> Render
- PostgreSQL -> Supabase
- Abstract files -> Supabase Storage
- Admin -> Django Admin

See [`DEPLOYMENT.md`](DEPLOYMENT.md) for setup instructions and required environment variables.
